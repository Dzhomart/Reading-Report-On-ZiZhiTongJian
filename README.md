# 资治通鉴读书笔记网站

一个展示《资治通鉴》读书笔记的中国古典风格静态网站。

## 项目结构

```
资治通鉴读书笔记/
│
├── index.html              # 首页
├── list.html               # 笔记列表页
├── detail.html             # 笔记详情页
│
├── css/
│   └── style.css           # 统一样式文件
│
├── js/
│   ├── main.js             # 公共函数和数据管理
│   ├── home.js             # 首页逻辑
│   ├── list.js             # 列表页逻辑
│   └── detail.js           # 详情页逻辑
│
├── data/
│   └── notes.json          # 笔记数据
│
└── README.md               # 项目说明文档
```

## 页面说明

### 首页 (index.html)
- Hero区域展示网站主题
- 精选笔记推荐
- 《资治通鉴》简介
- 阅读指引

### 笔记列表页 (list.html)
- 按朝代筛选笔记（秦纪、汉纪、晋纪、唐纪、宋纪、明纪）
- 笔记卡片展示
- 动态加载笔记数据

### 笔记详情页 (detail.html)
- 笔记标题和元信息
- 原文引用展示
- 详细笔记内容
- 相关笔记推荐

## 设计特点

- **中国古典风格**：宣纸质感背景、云纹装饰
- **主色调**：米白（#F5F0E6）、朱红（#C73E3A）、石青（#2E5984）
- **字体**：思源宋体（Noto Serif SC）
- **响应式设计**：适配桌面、平板和移动端

## 使用方法

1. 本地预览：使用任意HTTP服务器打开index.html
   ```bash
   # Python
   python -m http.server 8080

   # Node.js
   npx http-server
   ```

2. 直接打开：在浏览器中直接打开index.html文件（需允许本地JSON加载）

## 技术栈

- HTML5 语义化标签
- CSS3（Flexbox、Grid、CSS变量、动画）
- 原生 JavaScript ES6+
- Google Fonts（思源宋体）
